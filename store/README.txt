# STORE DAKHLA — PS4 Games Landing Page

## النشر على GitHub Pages
1. أنشئ Repository جديداً على GitHub (مثلاً: `store-dakhla-ps4`).
2. ارفع `index.html` ومجلد `assets` كما هما.
3. افتح Settings ثم Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر `main` و`/(root)` ثم Save.
6. انتظر قليلاً وسيظهر رابط الصفحة في قسم Pages.
